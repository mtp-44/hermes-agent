# Port the P1 security batch

## Context

[`HA-0008`](0008-security-triage-2026-09-24.md) triaged 85 upstream commits
and ranked a P1 batch, re-verified by hand: a redactor ReDoS on every log line
and outbound message, four secret shapes leaking, dangerous commands and
`approvals.deny` bypasses that ran unprompted, and a tap-to-prompt mismatch
upstream shares. The deny-glob and plist config mitigations went live the
same day, before this code.

## What landed

Three file-disjoint worktrees, merged with no conflicts:

- **Redaction (`sec/p1-redact`, 7 commits).**
  - **ReDoS:** `13ad903a3c` + `28524adb0e` + `fe0cfdf99c`. `'token'*1000` went
    from 21 s to 0.03 s, and `password=` + `'a.'*15000` from over 40 s to 3 ms.
    Output is identical on a 300k-input fuzz.
  - **Terminal classification:** `8ab9e79d0a` + `f5907fd052`. The broad
    `config.yaml.*` backup match is kept, because 15 of our ~20 copies are
    hand-named.
  - **Env-name suffixes:** `8563fe3435`(a) + `b41eee450b`'s word boundaries,
    applied only at the end of the keyword, so `dbpassword:` stays masked.
  - **Process list:** `8563fe3435`(b), `process(action=list)`.
  - **Secret-file reads:** `d205cef418` with `979576d938`'s linear line prefix.
  - **Python repr chain:** `47668280e7`, `92d4c0233e`, `5280dec0ee`.
  - **Local additions:**
    - The YAML/anchored-key passes used to switch off for a whole file that
      contained `://`. Every `config.yaml` has a `base_url`, so `api_key` came
      back in full; this also affected upstream.
    - Quoted YAML values in secret files.
    - `x-<name>-key` header names (`x-brain-key`).
- **Detection (`sec/p1-detect`, 4 commits).**
  - `4a9902d513`: zsh/ksh/dash, also in `skills_guard.py`.
  - **Local:** `sudo`/`env`/`nohup` launchers and fish/csh/tcsh after a pipe.
  - `58faa10134` + `50617d1c75` + `6178e9f4ee`: deny rules matched per command
    position, with whitespace collapsed, `env -S` split, `-a/--argv0`, a small
    shell `-c` payload parse, and comments stripped.
  - `679e07a074` + `ea870b4d3e`: launchctl label-before-verb, anchored.
    100 KB is checked in 0.1 s.
- **Approval binding (`sec/p1-taps`, 4 commits, local; upstream has the bug).**
  - Every queued gateway approval gets a `request_id`, and
    `resolve_gateway_approval(..., request_id=)` resolves only that entry.
  - Telegram buttons carry it. A tap on an expired or already-answered prompt
    resolves nothing and says so.
  - `approval.respond` in `tui_gateway` accepts it.
  - With more than one pending, the text prompt says which one `/approve`
    answers.
  - Outcomes are committed under `_lock` (the lock half of `2afb405337`), so
    an answer landing on the deadline isn't lost as a timeout. On `main`, a
    late tap on a timed-out prompt showed "Approved" and ran the next
    command.

Every new test was shown to fail before its fix and pass after.
Per-branch runs against `main` found zero new failures.

## Consequences and follow-ups

- The digest goes from 34 to **18 undecided**, the P2 set. `2afb405337` and
  `ba0f5839d4` are recorded as partial or not applicable.
- **Trailers overstate three ports:** `8563fe3435` part (c) (control-char
  splits, still P2 with `aecb9ca894`/`9377c5a539`); `979576d938`'s rc
  exemption (deliberately not taken); and the `cron/lifecycle_guard.py` half
  of `679e07a074`. The last is harmless while Hermes cron is disabled; revisit
  it if cron is re-enabled.
- **PWA renderer:** it still answers FIFO until it sends `request_id`. The
  change is in `use-message-stream/gateway-event.ts`, `store/prompts.ts`,
  `tool/approval.tsx` and `store/native-notifications.ts`, and the TUI has the
  same pattern. It needs a PWA release.
- **Other adapters still FIFO:** Discord, Slack, Feishu, Matrix, WhatsApp,
  QQ, Teams and api_server. None of them is used here.
- **New finding:** 400 levels of nested `$(` (1.2 KB) take the detector
  16.5 s. That is a separate, cheaper trigger than P2's `4eff83cdec`.
- **Out of scope, noted:** `hermes_cli/goals.py` sends raw process
  command/output to the goal judge. Process-list redaction runs on
  200-character slices, so a token cut at the edge can leak a fragment.
