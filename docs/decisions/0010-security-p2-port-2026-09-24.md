# Port the P2 security batch

## Context

[`HA-0008`](0008-security-triage-2026-09-24.md) triaged 85 commits.
[`HA-0009`](0009-security-p1-port-2026-09-24.md) landed P1, leaving 18
lower-priority commits in the digest. This record lands those, plus two
problems found while porting.

## What landed

Three file-disjoint worktrees merged with no conflicts. One renderer commit
was added on the integration branch.

- **Redaction (`sec/p2-redact`, 3 commits).**
  - Control-char and line-wrap splits: `8563fe3435`(c) → `aecb9ca894` →
    `9377c5a539`. The position remap is local; redacting a 1 MB log costs
    1.4× main (upstream's version costs 3×).
  - Dotted `sk-` and Zhipu `id.secret` keys: `7b57cda6d9` → `c2aa2ff25f` →
    `aebc71d78c`. Existing masks survive a second pass.
  - **Local:** the four config/YAML key patterns are now linear on keyword
    runs. They were quadratic or cubic, on main and upstream. A differential
    fuzz of 350k inputs matched exactly.
- **Detection (`sec/p2-detect`, 5 commits).**
  - Package uninstalls: `85ce25687e` + `ce0b10cb21`.
  - Docker/podman daemon redirects: `6437701228`.
  - deno/bun eval: `6ae1fab336` + `886df27c6e`.
  - Combined deobfuscation variant and faithful-quoting hardline:
    `4eff83cdec` + `e383c28d2f`. Detection variants for 460 quoted lines went
    from 462 to 4.
  - **Local:** interpreter `-c`/eval widening (`python3.12 -c`, `node --eval`,
    `perl -we`, `python3 - <<EOF`, …), a behaviour subset of `b90dbac1d6`,
    which is recorded as triaged.
- **Approval flow (`sec/p2-flow`, 7 commits).**
  - Allowlist: `7876d183c9` + `9b06d3d081`. A string value is ignored with a
    warning. A save merges with the file, so hand edits survive and removed
    entries stay removed.
  - `e37a0321eb`: `HERMES_EXEC_ASK` moved into `start_gateway()`.
  - Scope rendering: `165d1849e2`, `a3297bd232`, `02d8cbadec`, `a31a31826c`.
    Protected-file prompts offer Once and Deny only on the CLI, Telegram and
    Signal's text fallback. Mixed prompts offer Always again.
- **Renderer (`3fc339a417`, local).** The PWA/desktop bar now reads
  `allow_session`. Protected-file prompts no longer offer "Allow this
  session", and the options menu disappears when empty.

Every new test was shown to fail before its fix and pass after, and each
branch's run against `main` showed zero new failures by test id.
